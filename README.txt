PADANG DENDANG — WEBSITE RESTORAN

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder padang_dendang_web.
3. Klik dua kali index.html untuk melihat website di browser.
4. Koneksi internet diperlukan untuk Google Fonts dan foto menu dari Unsplash.

FITUR
- Landing page restoran dengan desain merah marun, gold, dan krem.
- Daftar menu dengan kategori dan pencarian.
- Harga menu, tombol tambah ke keranjang, pengaturan jumlah, dan total.
- Form detail pesanan dan format pesan WhatsApp.
- Bagian tentang restoran, rekomendasi menu, langkah pemesanan, dan lokasi.
- Tampilan responsif untuk HP dan laptop.

WAJIB DISESUAIKAN SEBELUM DIPAKAI
1. Buka script.js, cari `const whatsappNumber = "6281234567890";`
   Ganti dengan nomor WhatsApp resmi restoran, format kode negara tanpa tanda + atau spasi.
2. Di index.html, ganti teks alamat dan jam operasional contoh pada bagian Lokasi.
3. Sesuaikan nama menu, foto, deskripsi, dan harga pada array MENU di script.js.
4. Harga yang tersedia saat ini adalah HARGA CONTOH, bukan daftar harga resmi restoran.

CATATAN
Website ini merupakan website statis. Pesanan diteruskan ke WhatsApp setelah nomor restoran diatur. Tidak ada pembayaran online atau database pesanan otomatis.
